# 2.4 · Is it loaded? (5 นาที)

**เป้า:** แยก “ไฟล์ถูกส่งไป” ออกจาก “ทำตามกฎ”
อย่าเพิ่งสรุปว่า Copilot ดื้อ ถ้าเราสะกดชื่อไฟล์ผิดครับ

## ตรวจสามรอบ (4 นาที)

New Chat ทุกครั้ง ใช้ harness/model และ prompt เดิม:

```text
อธิบาย #src/loans.js ว่า buildFeeReceipt สร้างยอดและเวลาอย่างไร
อ่านเฉพาะไฟล์ที่จำเป็น ห้ามแก้ไฟล์
```

1. ส่งแล้วเปิด **References** ใต้คำตอบ มองหา `copilot-instructions.md`
2. Rename ด้วย Explorer เป็น `.github/copilot-instruction.md` (ขาด s)
   New Chat ส่ง prompt เดิม แล้วเช็ก References
3. **Rename กลับทันที** เป็น `.github/copilot-instructions.md`
   New Chat ส่ง prompt เดิม แล้วเช็กว่ากลับมา

อย่าแนบไฟล์กฎเองและอย่าสั่งให้อ่านมัน เรากำลังตรวจการใส่ให้อัตโนมัติ
อย่าใช้ chat เดิม เพราะประวัติยังมีกฎจากรอบก่อน

## ลองขอฝืนกฎ (1 นาที)

ใน chat ที่กฎกลับมาแล้ว ส่ง:

```text
เสนอ diff ให้ buildFeeReceipt ใช้ new Date() แทน clock.now()
แสดง diff อย่างเดียว ห้ามแก้ไฟล์จริง
```

จดว่า agent ยอม ปฏิเสธ หรือเสนอทางอื่น ไม่จำเป็นต้องยอมถึงจะผ่าน lab
คำว่า MUST ไม่ได้ทำให้ผลลัพธ์แน่นอน

**Done when:** จดทั้งสามรอบ แยก inclusion กับ compliance ได้ และชื่อไฟล์กลับถูกแล้ว

ถ้า References ไม่แสดง: ใช้ **Chat: Open Customizations** ตรวจ discovery
แล้วให้ trainer ช่วยดู request ใน Chat Debug
**discovered ≠ sent ≠ followed** สิ่งที่ตรวจไม่ได้ให้จดว่า “ตรวจไม่ได้”
ไม่เปลี่ยนเป็นผ่านเอง
