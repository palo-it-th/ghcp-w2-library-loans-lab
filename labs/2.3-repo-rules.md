# 2.3 · Write the repo rules (8 นาที)

**เป้า:** กติกาทีมไม่ต้องรอคนที่จำได้เข้าประชุม

## ทำ

1. อ่าน [กติกาทีม](../docs/team.md) เฉพาะเงิน เวลา และ migration (2 นาที)
2. สร้าง `.github/copilot-instructions.md` ด้วยคำของตัวเอง (5 นาที)
   แต่ละกฎมี **ต้องทำอะไร → เพราะอะไร → ดูโค้ดที่ไหน**
3. ตรวจรายการด้านล่าง แล้วไปต่อ (1 นาที)

โครงช่วยเขียน ไม่ต้องให้ Copilot อ่านทั้งการ์ด:

```markdown
# Library Loans house rules

- Money MUST ... because ... See src/money.js.
- Current time MUST ... because ... See src/clock.js and src/loans.js.
- Existing migrations MUST NOT ... because ... Add ... in db/migrations/.
```

เติมช่องให้เป็นกฎที่ทำตามได้จริง ไม่ใช้คำว่า “clean code” หรือ “best practice”
ประมาณ 10–20 บรรทัดก็พอ เป้าคือไม่เกินประมาณ 30 บรรทัด
นี่เป็นเป้าของ workshop ไม่ใช่ limit ของ GitHub

ยังไม่ใส่กฎตั้งชื่อ test ที่นี่ และไม่ย้ายขั้นตอน “เสนอ case แล้วรอ”
จาก prompt file มาไว้ในกฎทั้ง repo
ถ้า prompt ของคุณมีกฎที่จริงทุกงานอยู่แล้ว ให้ย้ายกฎนั้นมาไว้ไฟล์นี้ ไม่คัดลอกสองที่

**Done when**

- [ ] มีสามกฎสั้นๆ พร้อมเหตุผลและ path จริง
- [ ] แยกอ่านเวลาปัจจุบันออกจากการแปลงวันที่ที่ระบุไว้ได้
- [ ] ไม่มีขั้นตอนของงานเฉพาะกิจหรือกฎเฉพาะ tests ปน
