# 2.4 · Is it loaded?

**สิ่งที่จะฝึก:** แก้โค้ดเล็กน้อย แล้วดูว่า Copilot ได้รับกฎกลางและรัน test ตามกฎหรือไม่

## 0. ก่อนเริ่ม ลองเช็คดูว่า agent ของเรา load Copilot Instruction แล้วหรือยัง

ตรวจว่าไฟล์กฎกลางอยู่ที่ `.github/copilot-instructions.md` โดยตรง ไม่ใช่ใน `.github/instructions/`
ลองทักทายน้องด้วยคำว่า `สวัสดี` แล้วดูผล ถ้าตอบตาม Character แล้วถือว่าใช้ได้

## 1. Refactor แล้วดูว่ารัน test หรือไม่

ในไฟล์ต้องมีกฎจากข้อ 2.2 ว่าแก้ `src/loans.js` แล้วให้รัน `node --test tests/loans.test.js`
บันทึกงานที่ทำอยู่ก่อนเริ่ม ไม่ต้อง commit และไม่ใช้คำสั่ง reset งานเดิม
เปิด New Chat เลือก harness และ model เดิม แล้วส่ง:

```text
refactor countChargeableDays ใน #src/loans.js
```

1. ดู **References** ว่ามี `copilot-instructions.md` หรือไม่
   อาจจะไม่เห็นคำสั่งอ่านไฟล์ใน tool calls ในทุกครั้ง แต่ถ้าเช็คจากข้อ 0 แล้วใช้ได้เป็นอันโอเต
2. ตรวจ diff ว่า refactor โดยคงพฤติกรรมเดิม ไม่แก้ test หรือ function อื่น
   ยังไม่แก้เรื่องนับวันเสาร์อาทิตย์ เพราะเก็บไว้ทำในสัปดาห์ถัดไป
3. จดว่า Copilot รันคำสั่ง test อะไร และได้ผลอย่างไร พร้อมหลักฐานการแนบกฎ

ข้อนี้ทำครั้งเดียว เปิดกฎไว้ตลอด การเทียบตอนเปิดและปิดกฎอยู่ในข้อ 2.5

ใน prompt ไม่ได้สั่งให้รัน test เราจะดูว่า Copilot ทำตามกฎกลางหรือไม่
ยังไม่ต้องแก้รูปแบบ test เพราะเป็นเรื่องของข้อ 2.4
อย่าแนบไฟล์กฎหรือคัดลอกกฎลงใน prompt เอง และไม่ต้องเรียก `/write-tests`

**แยกหลักฐาน 2 อย่าง**

- กฎถูกแนบไปกับ request: ดู References หรือให้ผู้สอนช่วยตรวจเนื้อหากฎใน **System prompt**
- Copilot เปิดอ่านไฟล์ระหว่างทำงาน

ถ้าไม่มี Node หรือไม่ได้รับสิทธิ์รันคำสั่ง test ให้จดว่า “ยังไม่ได้รัน” พร้อมเหตุผล ไม่ให้คะแนนว่าผ่าน
เปิด `tests.html` ตรวจเองได้ แต่ไม่นับว่า Copilot รัน test สำเร็จ

## 2. ลองขอสิ่งที่ขัดกับกฎสักหน่อย

ใน chat เดิมส่ง:

```text
เสนอ diff ให้ buildFeeReceipt ใน #src/loans.js ใช้ new Date() แทน clock.now()
แสดง diff อย่างเดียว ห้ามแก้ไฟล์จริง
```

จดว่า Copilot ทำตามคำขอ ปฏิเสธ หรือเสนอทางอื่น
ไม่จำเป็นต้องทำให้ยอมฝืนกฎ การได้รับ instructions ไม่ได้รับประกันว่าจะทำตาม

เมื่อจบ ให้ Undo เฉพาะ refactor ที่ทำในข้อนี้ แล้วบันทึกไฟล์ โดยเก็บงานเดิมก่อนเริ่มแล็บไว้
ไม่ใช้ reset ทั้งไฟล์หรือทั้ง repo
