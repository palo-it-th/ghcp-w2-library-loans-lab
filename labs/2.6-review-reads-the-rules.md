# 2.7 · Review reads the rules (2 นาที · trainer demo)

ผู้เรียนไม่ต้องเปิด PR ไม่ต้อง push หรือรอ review ของตัวเอง

## ดู trainer ทำ

1. ดู PR ที่เตรียมไว้: function คิดค่าธรรมเนียมเป็น float บาท
   แต่ branch ของ PR มี `copilot-instructions.md` ที่กำหนด Money สตางค์
2. ผู้สอนเปิดผล Copilot Code Review ที่เตรียมไว้
3. เทียบ comment จริงกับกฎเรื่องเงิน แล้วจดผลใน worksheet

## จดผลที่เห็น

เลือกตามสิ่งที่ผู้สอนแสดง:

- **ทักเรื่องนี้:** มี comment ว่าโค้ดใช้ float บาทแทน Money หน่วยสตางค์
- **ไม่ทักเรื่องนี้:** มีผล review จริง แต่ไม่มี comment เรื่องหน่วยเงิน
- **ยังไม่ได้สาธิต review:** ไม่มีผล review จริงให้ดู จึงยังบอกไม่ได้ว่า Copilot ทักหรือไม่

ถ้ามี comment เรื่องนี้ ให้จดสั้น ๆ ว่า comment บอกอะไร

**ผู้สอนสรุป:** “เรามีกฎเรื่องเงินอยู่แล้ว รอบนี้จึงดูว่า review ทักโค้ดที่ขัดกับกฎหรือไม่”

## ก่อน share-out

- [ ] prompt file 1 ไฟล์ + repo instructions + test instructions ยังอยู่
- [ ] ไม่มีไฟล์ `.off` หรือชื่อ `copilot-instruction.md` ที่ผิด (ต้องมี s)
- [ ] tests ผ่าน และ worksheet มี observation จริง

เล่าหนึ่งอย่างในหนึ่งประโยค:
**เลิกพิมพ์อะไรซ้ำ / กฎโผล่เมื่อไร / คะแนนเปลี่ยนไหม / review ทักเรื่องอะไร**

เก็บ worksheet ไว้ต่อ W3/W4 ไม่มี homework
