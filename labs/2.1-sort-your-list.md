# 2.1 · Sort your list (5 นาที)

**เป้า:** เลือกที่เก็บให้ถูก ก่อนจะสร้างไฟล์จน repo กลายเป็นห้องเก็บเอกสาร

## ทำ

1. ใช้ประโยคที่จดจาก W1 หรือ [starter list](starter-list.md)
2. เลือกห้าประโยค จดใน [worksheet](worksheet.md) ว่าอยู่ที่:
   - chat ครั้งเดียว
   - prompt file ที่เรียกเอง
   - repo instructions ที่ติดไปทุกงาน
   - path-scoped instructions สำหรับบางไฟล์
   - procedure ที่พักไว้ทำ skill ใน W3
3. ใช้คำถามจากสไลด์ 4: ซ้ำไหม? เป็นกฎไหม? เฉพาะบางไฟล์ไหม? หลายขั้นไหม?
   ไม่ต้องใช้ Copilot และไม่ต้องสร้างไฟล์ใน lab นี้

**Done when:** แต่ละประโยคมีที่เก็บ และเลือกคำขอหนึ่งประโยคไปทำ prompt file ได้

**ติด:** เลือกประโยค “เสนอ edge cases แล้วรอก่อนเขียน test ให้ function นี้”
เป็นจุดเริ่มสำหรับข้อถัดไปได้เลย
