# ประโยคที่พิมพ์ซ้ำ · starter list

เลือกห้าประโยค หรือใช้ของตัวเองจาก W1 ไม่ต้องสร้างไฟล์ให้ครบทุกประโยค

1. อธิบาย stack trace อันนี้ให้หน่อย
2. สำหรับ function ที่ระบุ เสนอ edge cases แล้วรอฉันเลือกก่อนเขียนหนึ่ง test
3. เงินต้องคิดเป็นสตางค์จำนวนเต็มผ่าน Money ของ repo นี้
4. test ใหม่จัดกลุ่มด้วย describe ต่อ function ตั้งชื่อ camelCase และใช้ fakeClock ถ้าเกี่ยวกับเวลา
5. ทำให้เกิด bug ด้วย failing test ก่อน แล้วค่อยแก้และรัน test ซ้ำ
6. เพิ่มข้อความต้อนรับเฉพาะ ticket นี้
7. อ่านเวลาปัจจุบันจาก clock ที่ส่งเข้ามา ไม่ผูกกับเวลาเครื่อง
8. งานตรวจนี้ควรมีสิทธิ์อ่านอย่างเดียว ไม่ให้เครื่องมือแก้ไฟล์

ข้อหลายขั้นและข้อจำกัด tools พักไว้สำหรับ W3/W4
วันนี้ยังไม่สร้าง skill หรือ custom agent
