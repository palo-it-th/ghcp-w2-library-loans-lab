# 2.2 · Save the ask (7 นาที)

**เป้า:** คำขอเดิม เปลี่ยนแค่ input ไม่ใช่พิมพ์ใหม่จน keyboard ขอพัก

## 1. สร้าง prompt file (3 นาที)

สร้าง `.github/prompts/write-tests.prompt.md`:

```markdown
---
description: "Suggest edge cases for one function, then wait before writing one test"
agent: agent
---
For the function named after this command:
1. Read the function and [existing tests](../../tests/loans.test.js).
2. Suggest at most three missing edge cases.
3. Wait for me to choose ONE case before editing.
After I choose, add one test to the existing test file. Do not change implementation.
```

ไม่ต้องล็อก model หรือเพิ่มรายการ tools
link นับจากตำแหน่ง prompt file ไม่ใช่ root ของ repo

## 2. เรียกสอง input (4 นาที)

Local New Chat → พิมพ์ `/` → เลือก prompt ของ workspace:

```text
/write-tests calculateLateFee
```

คำตอบควรเสนอ case แล้วรอ **ยังไม่ต้องสั่งเขียน test**
Local New Chat อีกครั้ง:

```text
/write-tests buildFeeReceipt
```

**Done when**

- [ ] ไฟล์อยู่ใน `.github/prompts/` และชื่อจบด้วย `.prompt.md`
- [ ] คำสั่งเดิมรันกับสอง function และตอบถึงคนละ input
- [ ] บันทึกว่ารอให้เลือกจริงหรือไม่

ถ้า `/write-tests` ไม่ขึ้น: เช็ก Local กับ path แล้วลอง
Command Palette → **Chat: Run Prompt** หรือปุ่ม play ตอนเปิด prompt file
ถ้า Local ถูกปิด ให้สร้างไฟล์ไว้และจด **not run**
paste เนื้อหาเข้า chat ใช้อธิบายได้ แต่ไม่นับว่า prompt file รันแล้ว

ถ้าต้องการ checkpoint ให้ commit เฉพาะไฟล์นี้ในเครื่อง ไม่ต้อง push
