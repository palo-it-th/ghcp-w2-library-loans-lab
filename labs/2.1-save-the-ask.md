# 2.1 · เก็บคำขอไว้เรียกใช้ซ้ำ

**สิ่งที่จะฝึก:** เก็บคำขอที่ใช้บ่อยไว้ในไฟล์ แล้วลองเรียกใช้กับ function คนละตัว

## 1. สร้าง prompt file (3 นาที)

สร้างไฟล์ `.github/prompts/write-tests.prompt.md` ด้วย Ctrl+Shift+P เลือก `Chat: New Prompt File` แล้วใส่เนื้อหานี้:

ไฟล์นี้เก็บคำขอไว้เรียกใช้เอง ส่วนกติกาที่ให้ Copilot ใช้อัตโนมัติจะเขียนในข้อ 2.3 และ 2.5

```markdown
---
name: write-test
description: "เสนอกรณีทดสอบของ function ที่ระบุ แล้วรอให้เลือกก่อนเขียน test 1 ตัว"
---

สำหรับ function ที่ระบุหลังคำสั่งนี้:

1. อ่าน function และ [test ที่มีอยู่](../../tests/money.test.js)
2. เสนอ edge cases ที่ยังไม่มี test ไม่เกิน 3 กรณี
3. รอให้ฉันเลือก 1 กรณีก่อนเริ่มแก้ไฟล์
   หลังจากฉันเลือกแล้ว ให้เพิ่ม test 1 ตัวลงในไฟล์ test เดิม ห้ามแก้โค้ดที่นำมาทดสอบ
```

ตัวอย่างนี้ใส่เฉพาะ `description` เพื่อบอกว่า prompt ใช้ทำอะไร
ยังไม่ต้องระบุ model หรือกำหนด tools เพิ่ม
path ของ link ในตัวอย่างอ้างอิงจากตำแหน่ง prompt file ไม่ใช่จาก root ของ repo

## 2. ลองเรียกใช้กับ 2 function

เปิด New Chat เลือก Local และโหมด Agent แล้วพิมพ์ `/` เพื่อเลือก prompt ที่เพิ่งสร้าง จากนั้นส่ง:

```text
/write-tests #money.js
```

ดูว่า Copilot เสนอกรณีทดสอบแล้วหยุดรอให้เลือกหรือไม่ **ยังไม่ต้องสั่งให้เขียน test**
จากนั้นเปิด Local New Chat อีกครั้ง แล้วลองกับอีก function:

```text
# ใน loans.js
/write-tests calculateLateFee
```

**เช็กก่อนทำข้อต่อไป**

- [ ] ไฟล์อยู่ใน `.github/prompts/` และชื่อจบด้วย `.prompt.md`
- [ ] เรียกคำสั่งเดิมกับ 2 function ได้ และคำตอบตรงกับ function ที่ระบุ
- [ ] จดว่า Copilot รอให้เลือกกรณีทดสอบก่อนแก้ไฟล์หรือไม่

ถ้าไม่เห็น `/write-tests` ให้เช็กว่าเลือก Local และสร้างไฟล์ถูกที่แล้ว
การคัดลอกเนื้อหาไปวางใน chat ช่วยให้เห็นตัวอย่างคำตอบได้ แต่ยังไม่ถือว่าเรียกใช้ prompt file สำเร็จ

ถ้าต้องการบันทึกงานเป็น commit ให้ commit เฉพาะไฟล์นี้ในเครื่อง ยังไม่ต้อง push
