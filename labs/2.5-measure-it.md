# 2.6 · Measure it (11 นาที)

**เป้า:** ดูหลักฐาน ไม่วัดความมั่นใจจากน้ำเสียงของคำตอบ
“มั่นใจครับ” ไม่ใช่ assertion ครับ

## 1. Rules ON · ห้างานในคำตอบเดียว (4 นาที)

1. ตรวจว่าทั้งสอง instructions files ชื่อถูก แล้วจด model/harness ใน worksheet
2. New Chat ให้ reference file [sample tasks](sample-tasks.md)
   แนบเฉพาะ source ที่ระบุ โดยที่ไม่แนบ worksheet หรือกติกาทีม
3. ขอ proposed diff เท่านั้น ไม่สร้างไฟล์จริง ไม่ใช้ `/write-tests`
4. ดู References แล้วให้คะแนนแต่ละ task ใน [worksheet](worksheet.md)

| Task | ผ่านเมื่อ                                                  |
| ---- | ---------------------------------------------------------- |
| 1    | ใช้ Money คิด 550 สตางค์ × count ไม่คำนวณด้วย float บาท    |
| 2    | อ่านเวลาจาก argument `clock.now()` จริง ไม่อ่าน wall clock |
| 3    | ใช้ Money คิด 1990 สตางค์ × count                          |
| 4    | เพิ่ม migration ใหม่ ไม่แก้ `003_create_loans.sql`         |
| 5    | อ่านเวลาจาก argument `clock.now()` จริง                    |

แต่ละ task ให้ **1 / 0 / ?**: ทำตาม / ไม่ทำตาม / หลักฐานไม่พอ
ถ้ามี `?` จดว่า score ยังไม่ครบ อย่าเดาให้ผ่าน

## 2. Rules OFF · รันสองงานเดิม (4 นาที)

1. Rename ด้วย Explorer:
   - `.github/copilot-instructions.md` → `copilot-instructions.md.off`
   - `.github/instructions/tests.instructions.md` → `tests.instructions.md.off`
2. ปิด tab ของกฎและกติกาทีม ใช้ **New Chat**, model/harness เดิม
3. ส่ง preamble เดิมกับ **tasks 1–2 เดิมทุกคำ** ตัดเฉพาะ tasks 3–5
   ไม่แนบ worksheet หรือกฎที่ปิดไว้
4. ให้คะแนนสองงานด้วยเกณฑ์เดิม
   ถ้า agent แก้จริง ให้ Undo เฉพาะ edit ของการวัดก่อนรอบถัดไป

## 3. คืนไฟล์และเทียบอย่างยุติธรรม (3 นาที)

**Rename กลับทั้งสองไฟล์ทันที**
จดผลสองแบบ อย่าเอาตัวหารคนละจำนวนมาเทียบ:

- ห้างาน rules ON: **x/5** เป็นภาพรวมรอบนั้น
- เฉพาะ tasks 1–2 เดิม: **ON x/2 เทียบ OFF x/2**

คะแนนเสมอได้ ไม่มีใครต้องทำให้รอบ OFF ดูแย่
นี่เป็นตัวอย่างเล็ก ไม่ใช่ benchmark หรือข้อพิสูจน์เหตุและผล
profile/org rules อาจยังอยู่ จดไว้ ไม่ปิด policy ขององค์กร
รอบ OFF ถูกถามน้อยกว่าสามงาน จึงยังมี context confound แม้เทียบ subset เดียวกัน
ถ้าต้องการวัดจริง ให้รันครบห้างานทั้งสองเงื่อนไขหลายรอบนอกเวลา workshop

**Done when**

- [ ] มี ON x/5 และ matched ON/OFF x/2 พร้อมหลักฐาน
- [ ] บอกได้ว่ามีการใช้ instruction ที่กำหนดไว้หรือไม่
