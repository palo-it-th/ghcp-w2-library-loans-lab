# 2.7 · ดูว่า review ทักเรื่องกติกาทีมหรือไม่ (2 นาที · ผู้สอนสาธิต)

**สิ่งที่จะฝึก:** เทียบโค้ดใน PR กับกติกาทีม แล้วดูว่า Copilot review ทักเรื่องเดียวกับที่เราเห็นหรือไม่

ข้อ 2.6 ให้ Copilot เสนอโค้ด ข้อนี้เปลี่ยนมาดู **การตรวจโค้ดที่มีคนส่งมา**
ผู้สอนเตรียมตัวอย่างและผล review ไว้แล้ว ผู้เรียนไม่ต้องสร้างไฟล์ เปิด PR หรือ push

## ดู 3 อย่างตามผู้สอน

### 1. กติกาทีมว่าอย่างไร

ใน `.github/copilot-instructions.md` ของ branch ที่ส่ง PR มีกฎว่า:

> คำนวณเงินด้วย Money โดยเก็บเป็นสตางค์จำนวนเต็ม ไม่คำนวณด้วยทศนิยมหน่วยบาท

### 2. โค้ดที่ส่งมาต่างจากกฎตรงไหน

ตัวอย่างใน PR คือ `api/replacement.js` คิดค่าดำเนินการเปลี่ยนหนังสือเล่มละ 19.90 บาท:

```javascript
function quoteReplacementFee(count) {
  return count * 19.9;
}
```

ลองชี้บรรทัดที่ขัดกับกฎ: โค้ดคูณทศนิยมหน่วยบาทโดยตรง ไม่ได้ใช้ Money หน่วยสตางค์
แนวทางตามกฎคือคำนวณด้วย `Money.satang(1990).times(count)` ยังไม่ต้องลงมือแก้ในข้อนี้

### 3. Copilot review ทักเรื่องนี้หรือไม่

ผู้สอนเปิดผล review ที่ทำไว้ก่อนเริ่มเรียน หรือภาพผล review จริง
ดูว่ามี comment เรื่องการใช้ Money หรือการคำนวณเป็นสตางค์หรือไม่ แล้วจดตามที่เห็น
ถ้าทักเรื่องอื่น ให้แยกจากเรื่องที่เรากำลังตรวจ

ถ้ายังไม่มีผล review จริง ผู้สอนจะเทียบกฎกับโค้ดให้ดูเท่านั้น
ให้จดว่า **“ยังไม่ได้สาธิต Copilot review”** ไม่ใช่ “Copilot ไม่ทัก”

**เช็กก่อนจบ:** จดใน [แบบบันทึกผล](worksheet.md) ว่าโค้ดผิดกฎตรงไหน และผล review
**ทักเรื่องนี้ / ไม่ทักเรื่องนี้ / ยังไม่ได้สาธิต**

แม้ review ทักถูก ก็ยังพิสูจน์ไม่ได้ว่าเป็นเพราะอ่าน instructions เพียงอย่างเดียว
และการไม่ทักไม่ได้ทำให้โค้ดนี้ถูกกฎ เรื่องสำคัญยังต้องมี test หรือเครื่องมือช่วยตรวจ
