# 2.7 · Review reads the rules (2 นาที · trainer demo)

ผู้เรียนไม่ต้องเปิด PR ไม่ต้อง push หรือรอ review ของตัวเอง

## ดู trainer ทำ

1. ดู PR ที่เตรียมไว้: function คิดค่าธรรมเนียมเป็น float บาท
   แต่ branch ของ PR มี `copilot-instructions.md` ที่กำหนด Money สตางค์
2. Trainer เปิดผล **Copilot code review** ที่ซ้อมไว้ หรือ request ใหม่ถ้าพร้อม
3. ดู comment จริง: จับเรื่องหน่วยเงินได้ไหม? ถ้าไม่ได้ ให้จดว่าไม่ได้

คำถามหนึ่งข้อ: **ถ้าเรื่องเงินพลาดไม่ได้ ควรมีอะไรนอกจาก prose rule?**

กฎอาจช่วย review แต่ไม่รับประกันว่าจะจับได้ทุกครั้ง
comment ไม่ใช่ References list และการชี้ bug ไม่ได้พิสูจน์ว่ามาจากกฎอย่างเดียว

ถ้า policy/network ไม่พร้อม trainer ใช้ภาพ **review จริง** ที่บันทึกไว้
ถ้ายังไม่มีภาพ ให้ดู local diff แทนและระบุว่า **ยังไม่ได้สาธิต Copilot review**
ไม่ใช้คำตอบที่เขียนเองมาแสดงเป็นผลจาก Copilot

## ก่อน share-out

- [ ] prompt file 1 ไฟล์ + repo instructions + test instructions ยังอยู่
- [ ] ไม่มีไฟล์ `.off` หรือชื่อ `copilot-instruction.md` ที่ผิดค้าง
- [ ] tests ผ่าน และ worksheet มี observation จริง

เล่าหนึ่งอย่างในหนึ่งประโยค:
**เลิกพิมพ์อะไรซ้ำ / กฎโผล่เมื่อไร / คะแนนเปลี่ยนไหม / อะไรควรมี check**

เก็บ worksheet ไว้ต่อ W3/W4 ไม่มี homework
